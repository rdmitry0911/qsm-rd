# Historical MVP acceptance criteria

These acceptance criteria belonged to an earlier experimental transport and have been superseded by QSM Direct's real PVE 9 test gates. They are retained as an archival path only; they do not define the current package's supported behavior or performance target.

The active verification surface is documented in [qsm-direct/docs/TESTING.md](qsm-direct/docs/TESTING.md). It covers QEMU Display1, browser WebRTC, input, resize, full screen, clipboard, reconnect, concurrent viewers, and package layout.
