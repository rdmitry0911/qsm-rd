# Historical QMDP v1 proposal

QMDP v1 was a pre-QSM Direct protocol proposal. It is retained as a historical filename only and is no longer an implementation or interoperability contract.

The supported console uses PVE's authenticated same-origin API, private node-local Unix sockets, QEMU Display1 D-Bus, and browser WebRTC. See [qsm-direct/README.md](qsm-direct/README.md) for the current architecture and [qsm-direct/docs/TESTING.md](qsm-direct/docs/TESTING.md) for the acceptance suite.
