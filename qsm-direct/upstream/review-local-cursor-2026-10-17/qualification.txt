Independent LXC cursor and capture pacing — 2026-10-17
=====================================================

Implemented in the agreed order:
1. Optional private Sway 1.11/wlroots 0.19 compositor; separate cursor image,
   hotspot, position and visibility using ext-image-copy-capture-v1. Output
   video excludes the cursor. The existing shared cursor transport delivers
   the real sprite to the browser's native CSS cursor. Touch uses the newest
   local position. Unsupported compositors retain cursor-in-video capture.
2. Standard RTCRtpReceiver.jitterBufferTarget (milliseconds), with the older
   playoutDelayHint (seconds) as fallback. Used on track attachment and when
   settings change. Zero is a browser target, not a promise of zero buffering.
3. Capture starts are paced from the preceding start, removing the extra
   frame interval after completion. Pointer delivery sends isolated input
   immediately and coalesces continuous motion at 8 ms intervals. SCTP
   backpressure retains one newest position, with a 1024-byte send threshold.
   Click-position fences and keyboard/button events retain ordered delivery.
