Update, 23 October 2026: the current preview is stock4.1, with a standalone package for official PVE 9 and a signed APT repository. It also fixes repeated changes in static-text sharpness during network-rate adaptation; limited bandwidth now reduces motion cadence while retaining static reference detail.

Current source, matching packages, limitations and test reports:

The direct-UDP standalone profile uses a configurable signalling port starting at 18007. An optional, explicitly enabled single-node gateway supports a router forwarding only TCP 8006. Its HTTPS/WebRTC payloads are encrypted, while outer TURN control uses plain TCP. Please read the gateway guide before enabling it.

The original post below describes the first prototype. The native Proxmox integration remains a separate upstream proposal.
